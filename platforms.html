Supported systems

What Vaultgate manages

Sessions for any SSH, RDP or VNC system. Built-in password rotation for the platforms below, and your own platforms through custom command templates.

Password rotation

Each platform changes the password with its own command, then Vaultgate signs in with the new password to check it.

Sessions and access

Remote sessions

  • SSH (browser and native clients)
  • RDP
  • VNC
  • SFTP, SCP and rsync

Applications

  • Windows RDS RemoteApp programs
  • Database tools with a vaulted login
  • Admin consoles (MMC, ADUC)

Identity

  • Active Directory
  • LDAP
  • OpenID Connect single sign-on
  • TOTP authenticator apps

Clients

  • Any modern browser
  • OpenSSH and other SSH clients
  • HTTPS for the Credential API
