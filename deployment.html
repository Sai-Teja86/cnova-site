Deployment

Up and running in an afternoon

Vaultgate ships as a single installer that turns a VM or server into a ready appliance. No internet is needed to install it.

Installation

  1. Boot the installer on a VM or server and choose Install. It runs unattended and needs no internet.
  2. Read the address and one-time setup code on the appliance's screen. Set the network, host name and time there if needed.
  3. Open the web address and enter the setup code.
  4. Create the first administrator, with multi-factor sign-in on by default.
  5. Activate your license online, or start the 30-day trial.
  6. Add your directory, servers and accounts, and write your first policies.

Network ports

Only two ports are open on the appliance. Vaultgate connects out to your systems on their usual ports.

Running it

Failover

A primary, a warm standby and a small witness appliance. Users connect to a virtual address that moves to the standby about 45 seconds after the primary fails.

Backup and restore

Encrypted backups of the database, keys and, optionally, recordings. Restore onto a fresh appliance from the setup wizard.

Updates

Signed update bundles installed from the appliance console. A failover pair updates the standby and witness first.

Storage

Recording compression and retention, with disk alerts before space runs out.

Recovery kit

Emergency accounts in an encrypted file that opens offline, for the day the appliance is unreachable.

Licensing

Online activation with a daily check-in that tolerates 30 days offline, or offline activation with a license file for isolated networks. A 30-day trial on every new install.
