Getting Vaultgate

Vaultgate is self-hosted: it runs on your own VM or server, and your credentials, recordings and audit trail never leave your network. Cnova doesn't host your data.

Trial

Request a trial and we send the installer with setup help. Every new appliance runs for 30 days without a license.

Customers

Installers and updates are delivered by Cnova for each release, made for your organization. Check each file against the SHA-256 listed here before using it.

Signed updates

Every update is signed by Cnova. Appliances refuse a file that was changed or didn't come from us, and go back automatically if a new version doesn't start properly.

Release history

0.1.0-44

25 Nov 2026Security
  • Security-fix updates install after your update date. Updates marked as security fixes install on any licensed appliance, so a lapsed renewal never leaves a known hole open.
  • Operating system patches for offline appliances. Update bundles can carry Debian security updates. Each appliance installs only packages newer than its own, never older ones.

0.1.0-43

25 Nov 2026Security
  • License agreement shown and accepted in the setup wizard; which version was accepted is recorded in the audit trail.
  • Program file check. The appliance checks its program files against a list signed at build time, at startup and daily, and reports any change.
  • Updates follow the license. The License page shows the update date; updates released after it ask for a renewal.
  • Each installer carries a build identifier. The licensed customer's name appears in the console header and on PDF reports.

0.1.0-42

25 Nov 2026New
  • Offline license activation for networks without internet: a request code from the appliance, a license file back, no check-ins.
  • Console menu collapses to a narrow rail that opens on hover; user box moved to a top bar.

0.1.0-41

25 Nov 2026New
  • Control accounts on their own page: off by default, retrievable by administrators only. Windows domain control accounts.
  • MySQL and MariaDB are separate database engines. An asset's port and type follow the database chosen.

0.1.0-38 to 0.1.0-40

25 Nov 2026New
  • More database rotation: MongoDB, Redis, Valkey, Cassandra and SAP HANA. Db2 accounts rotate as operating-system accounts.
  • A landing page for visitors who open the appliance's address, and a refreshed look across the console and sign-in.

0.1.0-36 and 0.1.0-37

24 Nov 2026New
  • Custom platforms: administrators define the command steps that change a password on systems not supported out of the box.
  • Rotation by platform: one page that shows each platform's accounts and rotation state.

0.1.0-35

24 Nov 2026New
  • Database rotation: SQL Server, Oracle, MySQL and PostgreSQL logins, changed with each database's own statement and checked by signing in.
  • Network device rotation: Cisco IOS and IOS-XE, and FortiGate, through a control account on the device.
  • Vaultgate colour theme.

0.1.0-34

17 Nov 2026Changed
  • Credential API: every request needs the application's API key. Accounts can be chosen by asset/username.

0.1.0-33

16 Nov 2026New
  • Appliance console at /appliance/ with its own sign-in: License, Updates, Backup, Standby and failover, Storage and the Recovery Kit.

0.1.0-32

16 Nov 2026New
  • Credential API for scanners, pipelines and scripts: per-application keys, allowed addresses and accounts, every fetch audited.
  • Reachability check before onboarding.

0.1.0-31 and earlier

Oct to Nov 2026Foundation
  • Vault and rotation: encrypted credential vault, rotation policies, check-out and check-in, Windows and Linux rotation.
  • Sessions: brokered and recorded SSH, RDP and VNC in the browser; the SSH gateway for ssh, scp and sftp; RemoteApp applications; live monitoring, termination and replay; command blocking.
  • Access: deny-by-default policies, just-in-time approvals, MFA, roles.
  • Identity: Active Directory and LDAP domains, OpenID Connect single sign-on, group-based roles and leaver sync.
  • Onboarding: CSV import, Active Directory and Windows local account discovery.
  • Appliance: the installer ISO, setup wizard, licensing, encrypted backup and restore, warm standby, automatic failover with a witness, the recovery kit, signed updates with automatic rollback, storage alerts and reports.

Support and updates

Version numbers

0.1.0-44 is the product version followed by the build. A higher build is always newer, and appliances only ever move forward.

Update entitlement

Your license includes updates released up to its update date. Security-fix updates install on licensed appliances regardless of that date.

Operating system

Appliances run Debian 12. With internet access they install Debian security updates on their own; offline appliances get them in our update bundles.
